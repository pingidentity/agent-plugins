# Digital Credentials using PingOne Credentials

## Overview
PingOne Credentials enables organizations to create verifiable credentials and deliver them to compatible wallet applications. This area covers credential administration, wallet-app development, communications, and documented integration resources.

## Core Concepts
- **Verifiable credential creation:** Issuers create credentials for delivery to wallet applications, supporting digital credential distribution.
- **Credential lifecycle administration:** Organizations can create, modify, and administer credentials as their credential program evolves.
- **Wallet applications:** Developers can build and register a wallet application using the PingOne wallet native SDK, providing a compatible destination for credentials.
- **Credential notifications:** Customizable notification templates support credential-related communications.
- **Integration resources:** PingOne APIs, the PingOne Credentials Connector, Marketplace resources, and developer documentation provide documented integration paths.

## When to use
- Starting or planning a PingOne Credentials implementation.
- Managing credentials or developing a compatible wallet application.
- Connecting PingOne Credentials through documented APIs or the Credentials Connector.

## When not to use
- For detailed behavior of a particular API, connector, or SDK; consult that resource’s dedicated documentation.
- For topics not covered by this starting area, use the relevant PingOne Credentials documentation.
