# PingOne Credentials API

Use the PingOne Credentials API for credential profiles, issuance, lifecycle, wallet, and verifier operations documented for the service.

## Intent routing
| Request signal | Use when | Continue with |
|---|---|---|
| Credentials API | Discover and call supported Credentials resources | [PingOne Credentials API introduction](https://developer.pingidentity.com/pingone-api/credentials/introduction.html) |
| Issuance and wallets | Manage issuer profiles, issuance rules, wallet applications, or user wallets | [PingOne Credentials API introduction](https://developer.pingidentity.com/pingone-api/credentials/introduction.html) |
| Presentation and lifecycle | Manage presentation, verification, revocation, or expiration | [PingOne Credentials API introduction](https://developer.pingidentity.com/pingone-api/credentials/introduction.html) |
| Credential profiles | Configure or inspect issuer credential profiles | [Credential profiles](https://developer.pingidentity.com/pingone-api/credentials/credential-profiles.html) |
| Wallet application | Build the compatible wallet application experience | [PingOne Credentials documentation](https://docs.pingidentity.com/pingone/digital_credentials_using_pingone_credentials/p1_credentials_start.md) |
