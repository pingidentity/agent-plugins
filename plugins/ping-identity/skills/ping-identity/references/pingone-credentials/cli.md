# PingOne Credentials CLI

PingOne Credentials configuration can be managed using the [Ping CLI](https://developer.pingidentity.com/pingcli/latest/) developer tool.

```
pingcli credentials verify-policies --help
pingcli credentials credential-issuer-profile --help
pingcli credentials credential-types --help
pingcli credentials digital-wallet-applications --help
pingcli credentials user-digital-wallets --help
```

`pingcli pingone api` can be used to make direct API requests to manage PingOne Credentials configuration that may be not available to manage through native commands.
