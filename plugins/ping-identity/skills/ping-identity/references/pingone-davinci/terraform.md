# DaVinci Terraform

DaVinci configuration can be managed through [Terraform](../terraform/README.md).

- [**DaVinci Applications on the Terraform Registry**](https://registry.terraform.io/providers/pingidentity/pingone/latest/docs/resources/davinci_application)
- [**DaVinci Application Policies on the Terraform Registry**](https://registry.terraform.io/providers/pingidentity/pingone/latest/docs/resources/davinci_application_flow_policy)
- [**DaVinci Flows on the Terraform Registry**](https://registry.terraform.io/providers/pingidentity/pingone/latest/docs/resources/davinci_flow)
- [**DaVinci Variables on the Terraform Registry**](https://registry.terraform.io/providers/pingidentity/pingone/latest/docs/resources/davinci_variable)

## Gotchas

- The DaVinci Terraform provider at https://registry.terraform.io/providers/pingidentity/davinci/latest is deprecated.  Functionality has been moved to the PingOne Terraform provider.
