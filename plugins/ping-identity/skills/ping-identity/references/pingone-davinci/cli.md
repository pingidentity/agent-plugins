# DaVinci CLI

DaVinci configuration can be managed using the [Ping CLI](https://developer.pingidentity.com/pingcli/latest/) developer tool.

```
pingcli davinci applications --help
pingcli davinci connector-instances --help
pingcli davinci connectors --help
pingcli davinci flows --help
pingcli davinci variables --help
```

`pingcli pingone api` can be used to make direct API requests to manage DaVinci configuration that may be not available to manage through native commands.
