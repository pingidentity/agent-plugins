# Workforce Use Cases

## Overview
Workforce Use Cases is a catalog of solution guides for workforce identity, authentication, federation, application access, and administration. It helps organizations match needs to documented patterns across Ping products and enterprise systems.

## Core Concepts
- **Cross-tenant authentication:** PingFederate authenticates users from multiple Microsoft Azure AD tenants, supporting federated workforce access.
- **Authentication and recovery:** Guides cover adaptive and custom policies, Kerberos, Active Directory validation, password recovery, and passwordless sign-in.
- **MFA and delegation:** PingID integrations, VPN protection, and external identity providers support stronger or delegated sign-in.
- **Federation and applications:** SAML, OAuth/OIDC, FedHub identity bridging, PingOne Dock, and certificate maintenance connect identities to applications and services.
- **Access and connectivity:** PingAccess protection, single logout, directory and SQL datastores, and Pulse Connect Secure integration address enterprise access needs.

## When to use
- When choosing a documented scenario spanning PingFederate, PingOne, PingID, or PingAccess.
- When integrating directories, VPNs, external identity providers, or connected applications.

## When not to use
- Not as one end-to-end implementation guide; each scenario has its own guide.
- Not for assumptions about shared prerequisites, versions, architecture, licensing, or detailed configuration.
