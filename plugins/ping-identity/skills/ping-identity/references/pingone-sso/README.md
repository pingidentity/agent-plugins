# PingOne SSO

## Overview
PingOne SSO is a centralized sign-on service that lets users authenticate once and access multiple applications and services. It helps employees, partners, and customers use fewer separate credentials across locations and devices.

## Core Concepts
- **Centralized sign-on:** One authentication event provides access across multiple applications and services, reducing repeated sign-ins.
- **SAML:** A protocol PingOne SSO uses to communicate authenticated identity and authorization between services.
- **OAuth:** A protocol used to communicate authorization through encrypted tokens.
- **OpenID Connect (OIDC):** A protocol used to communicate authenticated identity and authorization through encrypted tokens.
- **Encrypted tokens:** Token-based communication carries identity and authorization information between participating services.

## When to use
- Provide streamlined access to multiple applications for employees, partners, or customers.
- Reduce the number of separate credentials users must manage across devices and locations.
