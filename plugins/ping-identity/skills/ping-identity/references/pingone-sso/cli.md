# PingOne SSO CLI

PingOne SSO configuration can be managed using the [Ping CLI](https://developer.pingidentity.com/pingcli/latest/) developer tool.

```
pingcli pingone applications --help
pingcli pingone groups --help
pingcli pingone identity-providers --help
pingcli pingone password-policies --help
pingcli pingone populations --help
pingcli pingone resources --help
pingcli pingone schemas --help
pingcli pingone sign-on-policies --help
pingcli pingone users --help
```

`pingcli pingone api` can be used to make direct API requests to manage PingOne SSO configuration that may be not available to manage through native commands.
