# Ping Advanced Identity Software

## Overview
Ping Advanced Identity Software is a self-managed identity platform covering access, identity and user-managed access, directory services, and gateway capabilities. It gives organizations a customizable foundation for self-managed deployment.

## Core Concepts
- **PingAM** delivers authentication, authorization, federation, and user-managed access.
- **PingIDM** supports identity synchronization, self-service, workflows, social identity, and lifecycle management.
- **PingDS** provides directory-server and directory-proxy services for identity data operations.
- **PingGateway** supplies edge security, agent-gateway, and open-finance capabilities at integration boundaries.
- **PingID** supports push MFA, transaction authorization, passwordless scenarios, and TOTP on mobile devices.

## When to use
- Choose it when self-managed identity capabilities, deployment control, and customization are requirements.
- Consider Kubernetes deployments when the team can operate supported containers and dependencies.

## When not to use
- Prefer PingOne or Advanced Identity Cloud when a managed identity service is a better fit.
- Reference images are for development and testing; Kubernetes infrastructure support comes from the platform vendor or partner.
