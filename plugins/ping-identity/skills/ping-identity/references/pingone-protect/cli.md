# PingOne Protect CLI

PingOne Protect configuration can be managed using the [Ping CLI](https://developer.pingidentity.com/pingcli/latest/) developer tool.

```
pingcli protect risk-policy-sets --help
pingcli protect risk-predictors --help
```

`pingcli pingone api` can be used to make direct API requests to manage PingOne Protect configuration that may be not available to manage through native commands.
