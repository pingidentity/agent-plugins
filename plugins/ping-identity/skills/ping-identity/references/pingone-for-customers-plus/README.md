# About PingOne for Customers Plus

## Overview
PingOne for Customers Plus provides customer journeys for registration, authentication, profile updates, and access recovery. It combines PingOne setup with ready-made DaVinci flows that organizations can adapt to their environment.

## Core Concepts
- **Onboarding setup:** Prepares supplied flows and can enable MFA and PingOne notifications, providing a foundation for customer journeys.
- **DaVinci configuration:** Variables and settings support environment-specific customization of supplied behavior.
- **Authentication choices:** Email magic links, email or SMS one-time passwords, FIDO2, voice, mobile apps, and TOTP address varied access needs.
- **Protection controls:** PingOne Protect is enabled by default and can be turned off when appropriate.
- **Flow lifecycle:** Supplied flows must be cloned for production use, separating templates from production customization.

## When to use
- Use it for prebuilt registration, sign-on, profile-management, and account-recovery journeys.
- Use it when customers need multiple authentication methods and configurable DaVinci behavior.

## When not to use
- It is not the complete DaVinci feature set; supplied components focus on common scenarios and selected practices.
- Review supplied flows and add customization when business compliance or regulatory obligations require more than they provide.
