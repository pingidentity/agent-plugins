# PingID

## Overview
PingID is a cloud-based, adaptive multi-factor authentication (MFA) solution within PingOne for Workforce. Its administration guidance covers configuring cloud authentication and managing the PingID service.

## Core Concepts
- **Service administration** covers service configuration and dashboard information for managing PingID.
- **Authentication administration** documents authentication types and configuration for administering MFA.
- **Policy management** covers PingID policy settings for applying authentication policies.
- **Branding** supports organizational branding for a recognizable authentication experience.
- **Offline MFA** covers authentication when normal connectivity is unavailable.
- **Operations** includes user life cycle management and reporting for managing users and reviewing activity.

## When to use
- Use this area to administer PingID MFA, service settings, authentication, policies, branding, Offline MFA, or operations.
- Consider it for integrations involving single sign-on, VPN or remote access, SSH, Windows or Mac login, AD FS, or Azure AD.

## When not to use
- It is not a guide to unrelated Ping products or workforce capabilities outside PingID.
- For end-user guidance, use the separate PingID end-user documentation.
- For implementation details beyond this index, consult the linked topic-specific documentation.

## Gotchas
- **The PingID adapter requires outbound internet access to PingID services** — blocking that egress makes MFA fail silently rather than erroring.
