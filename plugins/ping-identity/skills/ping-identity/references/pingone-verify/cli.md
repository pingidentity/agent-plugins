# PingOne Verify CLI

PingOne Verify configuration can be managed using the [Ping CLI](https://developer.pingidentity.com/pingcli/latest/) developer tool.

```
pingcli verify verify-policies --help
```

`pingcli pingone api` can be used to make direct API requests to manage PingOne Verify configuration that may be not available to manage through native commands.
