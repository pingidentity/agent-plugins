# PingOne Verify API

Use the PingOne Verify API for verification policies, proofing transactions, capture channels, results, and status handling. The API requires the `PING_ONE_VERIFY` product in the environment bill of materials.

## Intent routing
| Request signal | Use when | Continue with |
|---|---|---|
| Verify API | Start or manage documented identity-verification transactions | [PingOne Verify API](https://developer.pingidentity.com/pingone-api/verify/introduction.html) |
| Verify policies | Configure environment verification policies | [PingOne Verify API](https://developer.pingidentity.com/pingone-api/verify/introduction.html) |
| Verify transactions | Manage user transactions, documents, verified data, metadata, or identity assurance | [PingOne Verify API](https://developer.pingidentity.com/pingone-api/verify/introduction.html) |
| Policies and outcomes | Configure verification checks or interpret transaction outcomes | [PingOne Verify documentation](https://docs.pingidentity.com/pingone/identity_verification_using_pingone_verify/p1_verify_start.md) |
| Journey or app integration | Launch verification through AIC, PingAM, PingFederate, DaVinci, or mobile SDKs | [PingOne Verify documentation](https://docs.pingidentity.com/pingone/identity_verification_using_pingone_verify/p1_verify_start.md) |
