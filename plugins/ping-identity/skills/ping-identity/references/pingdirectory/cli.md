# PingDirectory CLI

Use the PingDirectory command-line tools for server administration, configuration, data movement, replication, and operational tasks.

## Intent routing
| Request signal | Use when | Continue with |
|---|---|---|
| Configuration | Inspect or modify server configuration | [`dsconfig` and available command-line tools](https://docs.pingidentity.com/pingdirectory/latest/pingdirectory_server_administration_guide/pd_ds_available_cmdline_tools.html) |
| Replication and data | Manage replication, backups, imports, or exports | [Available command-line tools](https://docs.pingidentity.com/pingdirectory/latest/pingdirectory_server_administration_guide/pd_ds_available_cmdline_tools.html) |
