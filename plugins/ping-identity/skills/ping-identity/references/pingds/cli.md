# PingDS CLI

Use the PingDS command-line utilities for server configuration, directory operations, replication, backup, and maintenance.

## Intent routing
| Request signal | Use when | Continue with |
|---|---|---|
| Server configuration | Manage PingDS configuration and services | [PingDS official documentation](https://docs.pingidentity.com/pingds/latest/index.md) |
| Directory operations | Perform LDAP, replication, backup, or maintenance tasks | [PingDS official documentation](https://docs.pingidentity.com/pingds/latest/index.md) |
