# PingIDM (Identity Management)

## Overview
PingIDM centrally manages and synchronizes identities for users, devices, and things. It is designed to support varied identity-management use cases and workflows.

## Core Concepts
- **Central identity management** — Provides a managed capability for identity information, helping organizations coordinate identity-related operations.
- **Identity synchronization** — Keeps identity information aligned across relevant systems or contexts, supporting consistent identity data.
- **Users, devices, and things** — Covers these identity subjects explicitly, supporting identity-management scope beyond users alone.
- **Varied use cases and workflows** — Accommodates different scenarios and operating patterns rather than prescribing one workflow.

## When to use
- When an organization needs to manage and synchronize identities for users, devices, or things.
- When identity requirements span multiple use cases or workflows.

## When not to use
- For version-specific features, deployment requirements, compatibility, fixes, deprecations, or discontinued functionality; use the applicable versioned release notes.
- When the requirement is outside identity management; select documentation for the relevant Ping product area.
