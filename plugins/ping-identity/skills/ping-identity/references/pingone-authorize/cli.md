# PingOne Authorize CLI

PingOne Authorize configuration can be managed using the [Ping CLI](https://developer.pingidentity.com/pingcli/latest/) developer tool.

```
pingcli authorize api-servers --help
pingcli authorize application-resource-permissions --help
pingcli authorize application-roles --help
pingcli authorize decision-endpoints --help
```

`pingcli pingone api` can be used to make direct API requests to manage PingOne Authorize configuration that may be not available to manage through native commands.
