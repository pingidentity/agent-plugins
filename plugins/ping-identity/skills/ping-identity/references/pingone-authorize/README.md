# Authorization using PingOne Authorize

## Overview
PingOne Authorize is a cloud service that controls what end users can view and do in applications and APIs. It centralizes authorization requirements so organizations can adapt them as use cases and regulations change.

## Core Concepts
- Fine-grained policy rules support requirements ranging from simple to real-time authorization.
- The Trust Framework provides reusable building blocks for authorization policies.
- Policy deployment and decision evaluation turn configured policies into access outcomes.
- Decision review supports examination of authorization decisions.
- API definitions identify protected operations and resources.

## When to use
- Centrally authorize application and API access or protect sensitive API resources.
- Evaluate individual or bulk authorization decisions.
- Integrate authorization with API gateways, CloudFront, DaVinci flows, or external OAuth servers.

## When not to use
- For requirements outside authorization, policy management, decision evaluation, or documented integrations; consult the relevant Ping product area.
- When a general-purpose application platform is needed; this area covers an authorization service.
