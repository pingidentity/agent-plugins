# PingOne Authorize API

Use the PingOne Authorize API for centralized, fine-grained, attribute-based policy decisioning and documented authorization operations.

## Intent routing
| Request signal | Use when | Continue with |
|---|---|---|
| Policy decisions | Evaluate a policy decision for an application or API request | [Authorization decisions API](https://developer.pingidentity.com/pingone-api/authorize/authorization-decisions.html) |
| Bulk decisions | Submit documented bulk authorization decisions | [Authorization decisions API](https://developer.pingidentity.com/pingone-api/authorize/authorization-decisions.html) |
| API access management | Work with protected API definitions and access management | [API Access Management API](https://developer.pingidentity.com/pingone-api/authorize/api-access-management.html) |
