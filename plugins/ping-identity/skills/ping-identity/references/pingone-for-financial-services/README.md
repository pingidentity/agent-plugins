# About Financial Services

## Overview
PingOne for Financial Services combines PingOne and DaVinci to provide a guided onboarding experience and prebuilt flows. It helps end users securely make payments and transfers while managing account and privacy settings.

## Core Concepts
- Threat detection identifies bots, disposable-email use, and adversary-in-the-middle attacks, helping protect financial-service interactions.
- Risk evaluation classifies indicators as high, medium, or low threat to help reduce account-takeover risk.
- Flexible authentication supports email magic links, email and SMS one-time passwords, FIDO2, voice, mobile apps, and TOTP.
- PingOne configuration supports multi-factor authentication and notifications, while DaVinci configuration adapts variables and flow behavior to an organization’s environment and users.
- Production preparation uses cloned DaVinci flows, allowing the supplied flow configuration to be adapted before deployment.

## When to use
- Financial-service experiences that include payments, transfers, account administration, or privacy controls.
- Deployments needing configurable, prebuilt authentication and threat-detection flows.

## When not to use
- Do not treat the solution as a catalog of every DaVinci capability; it focuses on selected common scenarios and practices.
- It requires both PingOne and DaVinci, with environment configuration before flow use.
- Review supplied templates for business, compliance, and regulatory needs; customization may be necessary.
