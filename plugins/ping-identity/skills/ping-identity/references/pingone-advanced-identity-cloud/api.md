# PingOne Advanced Identity Cloud API

Use the Advanced Identity Cloud documentation and its tenant-specific API guidance for identities, applications, journeys, provisioning, federation, and tenant operations. Do not substitute PingOne multi-tenant APIs.

## Intent routing
| Request signal | Use when | Continue with |
|---|---|---|
| Identity and applications | Manage identities, applications, or connected services | [Advanced Identity Cloud documentation](https://docs.pingidentity.com/pingoneaic/home.html) |
| Journeys and authentication | Configure registration, login, recovery, or authentication journeys | [Advanced Identity Cloud documentation](https://docs.pingidentity.com/pingoneaic/home.html) |
| Provisioning and federation | Connect directories, applications, or OIDC/SAML/WS-Federation partners | [Advanced Identity Cloud documentation](https://docs.pingidentity.com/pingoneaic/home.html) |
