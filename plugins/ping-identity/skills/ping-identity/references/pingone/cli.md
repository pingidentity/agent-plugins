# PingOne CLI

PingOne configuration can be managed using the [Ping CLI](https://developer.pingidentity.com/pingcli/latest/) developer tool.

```
pingcli pingone active-identity-counts --help
pingcli pingone admin-config --help
pingcli pingone custom-domains --help
pingcli pingone environments --help
pingcli pingone gateways --help
pingcli pingone languages --help
pingcli pingone licenses --help
pingcli pingone notification-policies --help
pingcli pingone notification-templates --help
pingcli pingone webhooks --help
```
