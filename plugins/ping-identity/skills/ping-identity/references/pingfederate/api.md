# PingFederate API

Use the PingFederate product documentation for administrative and runtime federation APIs. Confirm the installed release before generating requests for connections, adapters, authentication policies, or OAuth/OIDC configuration.

## Intent routing
| Request signal | Use when | Continue with |
|---|---|---|
| Federation administration | Manage IdP/SP connections, adapters, or protocol settings | [PingFederate official documentation](https://docs.pingidentity.com/pingfederate/latest/index.md) |
| Authentication and policy | Configure authentication policies or application access | [PingFederate official documentation](https://docs.pingidentity.com/pingfederate/latest/index.md) |
| OAuth and OIDC | Manage token and client configuration | [PingFederate official documentation](https://docs.pingidentity.com/pingfederate/latest/index.md) |
