# PingFederate CLI

PingFederate configuration can be managed using the [Ping CLI](https://developer.pingidentity.com/pingcli/latest/) developer tool.

```
pingcli pingfederate --help
```

`pingcli pingfederate api` can be used to make direct API requests to manage PingFederate configuration that may be not available to manage through native commands.
